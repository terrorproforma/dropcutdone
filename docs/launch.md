# Launch sequence

1. Confirm primary hostname and DNS access. Attach the domain and verify TLS. Update canonical/sitemap/robots to that hostname.
2. Review cutout quality on seller photos, mobile Safari and Android Chrome; verify failed files cannot block the queue. Test throughput before making performance claims.
3. Publish the free beta publicly when authorized. The current Sites preview is owner-private.
4. Add first-party aggregate funnel measurements: accepted photo -> successful processing -> download, with error rates. Count unique completed users without storing images or sensitive metadata.
5. Recruit the first 100 completed users through authorized channels. No paid ads or outreach have been started.
6. Use observed demand and repeat usage to define the paid offer. A free local tool alone does not establish $1,000/day economics.
7. For paid cloud batches: add a commercially usable higher-quality model, metering, a real hosted checkout, signed payment webhooks, an idempotent credits ledger, refunds, account recovery, and support. Expose the administrative operations through authenticated tools with spend and refund limits.

The public launch, domain DNS, analytics, paid plans, and autonomous commercial operations are not completed by this initial beta.
